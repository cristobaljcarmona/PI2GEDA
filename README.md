# Biblioteca abierta del proyecto PI2GEDA

Documentación de acceso libre del proyecto **PI2GEDA, Plataforma Inteligente para la Interoperabilidad y Gestión de Espacios de Datos Agrícolas**. Reúne documentación técnica divulgativa, manuales de usuario, guías de capacitación, políticas y procedimientos, y los resultados y la difusión del proyecto.

PI2GEDA desarrolló una plataforma para que agricultores, asesores y aplicadores lleven el cuaderno de explotación de forma sencilla: registro de operaciones por voz con revisión del usuario, estructuración de la información con inteligencia artificial y reglas del catálogo oficial, lectura de albaranes, recomendaciones fitosanitarias e interoperabilidad con los registros oficiales (SIEX, SIGPAC, REA, ROMA y ROPO), con el titular de la explotación en control de sus datos.

Acceso a la aplicación para usuarios autorizados: https://pi2geda.indesal.net
